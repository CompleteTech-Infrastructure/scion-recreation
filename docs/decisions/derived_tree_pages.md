# Decision: separate deterministic derived directory pages

Status: FND-TREE-CONTRACT attempt-1 author candidate, awaiting two independent reviews and integration verification. Scope: R09/R36/R37/R56, C1/C2; three leased product files only. This is an original product design, not a claim about Anthropic internals.

Accepted FND-03 integration `390e581d7b480f40cf25c03a9c54a0f23dd66f53` freezes canonical v1 kinds 01/02 and excludes persistent trees. Accepted FND-09 integration `e36746dec8c473228f8083dc96365f31a77d2d39` requires protected projections and grants for every delivery. Their exact document hashes are `eceab23e153e7d96558858ef76448d41b34bf844315b5d37cea4f0404df4b9c2` and `ed748131108d155d578b8e4d72c7977a63ce0c1c8ab248db3055eb5933745a1e`. Neither document changes here. Owner ADR-007 approves the 30-second maximum as a design target, not demonstrated enforcement.

Choose the separate `canopy-tree:1:01` / `CTP\0` identity namespace and `CANOPY\0TREE\0` SHA-256 domain specified in `api/contracts/tree_pages.md`. Choose per-directory persistent unsigned-byte radix maps. A terminal distinguishes modes and directories, allowing a component to be a prefix of another component without conflating file ancestry. All canonical-valid byte components and paths remain representable; host filename conventions cannot shrink scope.

Compression ends at fixed component-byte offsets 255 modulo 256. This additional anchor is essential: naively restarting 255-byte fragments after every branch would let a deletion shift every fragment in a surviving long name. Anchors preserve the later continuation while allowing deterministic maximal compression within each interval. Complete frames are bounded by 10,478 bytes with fanout 254; a 65,535-byte single component needs 256 pages. These are derived bounds, not performance results.

Reject a flat directory object: a one-entry change would rewrite a very wide directory. Reject fixed sorted groups: inserting an early entry shifts later groups. Reject canonical kind 03 and disguised blob trees: they violate the accepted identity registry. Hash-addressed immutable pages with normalized anchored path copying provide equal roots for equal maps independently of insertion/deletion history, while unchanged subtrees retain their identities.

Publish mappings only after bottom-up durable page validation and retention. Compare terminal results per immutable input/version key; differing roots are corruption, not last-writer-wins. Missing, pending, completed empty, deterministic negative and corrupt states remain distinct. No global lock or sequence is introduced; actual database primitives and durable receipt/GC coordination require later adapter evidence.

Keep raw pages internal. Protected projections have a separate authority-issued identity bound to source/repository, effective view, policy, exact ROOT/PATH selection, algorithm and visible content. Private bindings use randomized public aliases even for repeated identical requests, so equality does not reveal hidden-only revision changes. A projection is neither a raw page nor authorization. Concrete public projection serialization belongs to FND-PROJECTION-CONTRACT; accepted security obligations cannot be postponed or replaced by returning these raw pages.

The companion fixture and external finite models are contract evidence only. The normative shape definition is intentionally independent of an efficient runtime implementation. IDX-03 must prove byte conformance, bounded updates, subtree reuse, crash-safe publication and real storage behavior. Production scalability, cloud behavior and the approved revocation target remain unverified. Retain those gates and all original requirements; do not mark this author candidate accepted or the runtime complete.
